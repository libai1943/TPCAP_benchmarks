Plan the maneuver.

Twenty preliminary-round cases, one compact numeric format.

The released CSV files describe the initial and target rear-axle poses and obstacle polygons. Positions are in meters; headings are in radians. Each file in this release stores one comma-separated row; readers should treat it as a flat numeric vector.

Decode the vector.

Entries (one-based)Meaning
1–3Initial x, y and heading
4–6Target x, y and heading
7Number of obstacles, m
8 through 7 + mVertex count for each obstacle
Remaining entriesInterleaved x, y coordinates of each polygon, in order

For two quadrilateral obstacles, the vector has 25 entries: six pose values, one obstacle count, two vertex counts and sixteen coordinate values. Obstacles can be nonconvex; preserve the supplied vertex order.

The vehicle reference point.

The x and y coordinates describe the rear-axle midpoint. The companion viewers use a 2.8 m wheelbase, 0.96 m front overhang, 0.929 m rear overhang and 1.942 m width. These dimensions are defined by the demos, not stored in the scene CSVs.

The illustration shows scene inputs, not computed trajectories.

Start with a viewer.

The MATLAB demo and Python demo load and display all twenty scenes. The repository README includes minimal loaders in both languages. These viewers do not run the historical scoring controller.
